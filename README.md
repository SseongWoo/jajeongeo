# 자전거(자유로운 전공책 거래)

## 프로젝트 소개

대학교 생활에서 학생들이 겪는 전공 및 교양 서적의 높은 가격과 커뮤니티 소통의 불편함을 해결하기 위해 기획된 애플리케이션입니다. 주요 목표는 다음과 같습니다:

1. **전공/교양책의 높은 가격 문제 해결**
   - 기존 온라인 중고 거래 플랫폼(알라딘, 당근마켓, 에브리타임)의 단점 보완
     - 알라딘: 온라인 중고 서점이지만 판매자는 싸게 팔아야 하고, 구매자는 비싸게 사야 하는 구조로 불리함
     - 당근마켓: 책 거래가 주요 카테고리가 아니어서 원하는 책을 찾기가 어려움
     - 에브리타임: 책 거래를 위한 별도 시스템이 없고, 게시판 형태로 운영되며 사용자 간 직접적인 가격 비교가 어려움
   - 바코드 인식 기능을 활용하여 도서 정보를 자동으로 불러오고, 적정 가격을 제공
   - 판매자와 구매자가 실시간 채팅을 통해 원활한 소통 가능
   - Naver Maps API를 활용하여 거래 장소 설정

2. **학교 커뮤니티의 개선**
   - 기존 커뮤니티(페이스북, 에브리타임)의 단점 해결
     - 페이스북: 학생 인증 절차가 없어 외부인이 쉽게 접근 가능하여 커뮤니티 신뢰성이 낮음
     - 에브리타임: 강원대학교 삼척캠퍼스의 경우 도계캠퍼스 학교 커뮤니티가 통합되어 있어 특정 캠퍼스 학생만의 정보 공유가 어려움
   - 학교별, 학과별, 학과 계열별 커뮤니티 제공으로 정보 공유 최적화
   - Firebase를 통한 학교 이메일 계정 인증을 활용하여 학생 신분을 확인하고 외부인의 접근을 차단

이 애플리케이션을 통해 학생들은 보다 저렴하게 책을 사고팔 수 있으며, 안전하고 원활한 커뮤니티 환경에서 정보를 교류할 수 있습니다.

## 개요
- 프로젝트 : 대학생 사용자간 책을 거래하거나 소통할 수 있는 어플리케이션
- 분류 : 단체 프로젝트
- 제작기간 : 22.03 ~ 22.06
- 사용기술 : Java, FireBase Authentication, FireBase Cloud Firestore, FireBase Storage, FireBase Realtime Database, Naver Api
- 사용 IDE : Android Studio
- 사용 디바이스 : Galaxy Z Flip 3

## 🔹 주요 기능
### 📚 **중고 서적 거래 기능**
- **바코드 인식 (Zxing 라이브러리 활용)** → 책 정보 자동 조회  
- **네이버 도서 API 연동** → 정가 및 도서 정보 제공  
- **판매자-구매자 실시간 채팅** (Firebase Realtime Database 활용)  
- **Naver Maps API 적용** → 거래 장소 설정 기능  

### 🏫 **학교 기반 커뮤니티**
- **학교 커뮤니티** → 해당 학교 학생들의 자유로운 소통 공간  
- **학과 커뮤니티** → 해당 학교 내 동일 학과 학생 전용 커뮤니티  
- **학과 계열 커뮤니티** → 전국 동일 계열 학과 학생들이 소통하는 커뮤니티  
- **학생 인증 시스템** → Firebase Authentication의 이메일 인증과 학교 이메일 시스템을 활용하여 신뢰성 확보  

### 💬 **실시간 채팅 기능**
- Firebase Realtime Database 기반 1:1 채팅 지원  
- 지도 공유 기능 (거래 장소 공유 가능)
